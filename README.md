# Watch Together

A premium, production-grade MERN stack video streaming platform.

## Architecture

- **Frontend:** React, Vite, Tailwind CSS, React Router DOM, Axios
- **Backend:** Node.js, Express.js, MongoDB Atlas
- **Features:** Video Streaming, Watch Parties, Subscriptions, Comments (To be implemented in phases)

## Setup

### Prerequisites
- Node.js (v18+)
- MongoDB Atlas Account

### Backend
1. `cd backend`
2. `npm install`
3. Copy `.env.example` to `.env` and fill variables.
4. `npm run dev`

### Frontend
1. `cd frontend`
2. `npm install`
3. Copy `.env.example` to `.env`.
4. `npm run dev`
